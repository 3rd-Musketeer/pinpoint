用 HTML 冲出像素级的 iOS 原型

一个跑在浏览器里、agent 会用的「Figma」：你提需求、在画布上标注，agent 负责搭屏和改稿。纯 HTML/CSS，改一行热更新一行。

词汇表

这些词是你和 agent 的共同语言——画布、标注文件、skill 文档里说的都是同一套名字。

画布层级（也是标注的地址体系）

Page页
侧栏里的一块板，一个探索主题一页。Component Library 永远排第一，是系统自动生成的。「在 smart-todo 这页加个 section」
Section段
板上的一组屏：一条 flow（row 横排）或一摞方案（column 纵排）。AB 对比就是一个 row section 放两屏。
Frame框
板上的一台手机（含壳）。手机壳由加载器负责，不是编辑对象。
Screen屏
frame 里的 iOS 内容，对应一个 HTML 文件（previews/<page>/<screen>.html）。agent 的主要工作面。「把 timer 这屏的按钮改成两个」

组件

Component Library
自动合成的首页，陈列 components/ 下所有组件的全部 variant——相当于 Figma 的组件面板。
Component / Variant
跨屏复用的元素（如消息气泡的 incoming / outgoing 两个 variant）。屏里用 include 引用，改一处、所有引用处一起刷新。「把气泡抽成组件，两屏都用它」

评审

交互 / 标注两种画布模式
交互（默认）：像真 app 一样点——tab 切换、sheet 弹出、手势都能玩。标注（按 A）：点选 / 框选元素写评审意见。
Annotation标注
一条评审意见：正文 + 锚定的元素 + 可选的参考图 / 移动箭头 /「改文案」。落在你机器的磁盘上，agent 直接读。
Indicator定位符
贴给 agent 的短地址：@page:library、@frame:library/timer、@a:ab12cd（单条）。标注框和 Pages 列表的 🔗 一键复制。「@section:library/brew-flow 下的标注都处理一下」

底座（知道存在即可）

Kit
ios-kit.css/js：HIG 精确的 iOS 组件与 token（对标 Figma Variables）。它保证原型「长得像真 iOS」——中文排版安全、真 iOS points、light/dark 一键切。
Shell
屏的壳形态：默认 app 壳，锁屏用 lock 壳（时钟 + 通知那种）。
交互屏A / B 两种形态
屏可以带自己的手势和动画：短逻辑内联在屏文件里（A），长逻辑放同名 sidecar JS（B）。示例：Example Library 的冲煮计时器。「给这屏加个可以拖的进度环」

画布怎么开

操作手势
缩放⌘ + 滚轮，或右下角 ±；点百分比回 100%
平移Space + 拖拽，或中键拖拽
跳转右下角 Section Navigator / 分层 minimap，连续跳不关面板
切模式A 在 交互 ↔ 标注 之间切
整机标注点屏标题或手机壳；⌥ + 点屏内元素也升级到整框
主题 / 字号侧栏底部 Light / Dark；设置里有 Dynamic Type 三档

评审三步

标：按 A，点选或框选元素，在底部输入框写意见。可以连续点选多个目标、贴参考图、画「移动到」箭头、勾「改文案」。
喊：跟 agent 说「标好了，你看一下」（要指定范围就贴 indicator）。它按 page → section → frame 分组读盘，逐条改源文件，画布热更新。
清：确认改对了，删掉或清空这批标注，进下一轮。已失效的锚点会标「锚点失效」，不会静默丢。

两条边界

标注是单机的。落在你机器的 ~/.html-annotate/，工作单元是「一个人 + 他的 agent」——这不是多人 Figma，结论靠改稿落地传递。

手机壳不归你俩管。bezel / 状态栏 / 底部横条由加载器统一画，agent 的约定里也禁止碰它——评审意见提内容和布局就好。

更细的东西：README（配置 / class 词汇表 / 设计规则）· AGENTS.md（agent 契约，人不用读）。

示例 app「冲煮手账 ☕ 全虚构」就是用这套 kit 搭的——逛一遍 Example Library，所有机制都在里面。
