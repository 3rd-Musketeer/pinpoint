# DESIGN — pinpoint 设计语言正典

当前有效的设计语言只写在这里；被取代就改本文，不留尸骸。

分工：本文 = **现在是什么样**（正典）。为什么这么变、什么时候定的 → [docs/adr/](adr/)（索引与格式见 [adr/README.md](adr/README.md)）。某个 token 值的理由 → `scripts/build-wb-tokens.mjs` / `src/workbench/wb-tokens.css` 注释。UI 文案（写什么字）→ workspace 的 topics/text-quality/ui-text.md，本文引用不复制。

外壳现在的形态是画布满铺 + 浮动玻璃面板 + 底部横条 + 右下按需浮层，2026-09-04 定，见 [adr/0031](adr/0031-shell-glass-panel-bottom-strip-on-demand-list.md)。

## 原则

1. **装饰即功能**：每个视觉元素必须回答“它标记、组织或反馈什么真实信息”。答不上来就删（判例：铭牌铆钉、画布角十字，ADR 0012）。
2. **层级靠线宽与明度阶梯，不靠颜色数量**。三级线各有语义：发丝（格内细分）→ 结构缝 `--wb-seam`（pane 分界）→ 图框（sheet 边界）。
3. **复古感由字体与编号体系承载**（mono + tabular-nums + 字距 + A1 / REV 这类编号词汇），不由质感贴皮承载（做旧、铆钉、假材质）。
4. **丰富由真实数据产生**；系统的职责是 hold 住它，不加戏。
5. **全场只允许一个签名物**（当前 = REV chip）。一个是意图，十个是噪音。
6. **情感来自行为的周密**（hover 联动、即时回显、克制动效），不来自表皮。

## 色彩

- 画布纸 `#f5f6f8` 冷中性（`--wb-stage-bg`，Radix slate 2–3 之间）；chrome 是压在画布上的玻璃面板；ink `#1c2024`；muted `#6b6b70`。ADR 0031 用这张冷纸取代了 ADR 0010 的暖纸 `#faf8f4`——暖纸配蓝灰网格再配白 chrome，冷暖打架。
- accent = 钢灰蓝 `#5b7fa6`：可交互 / 当前 / 系统标注语义；全页唯一实心 on 态（现在是横条上的“标注”段）。chrome 与 iOS kit 内容分色，内容侧 `#007aff` 不变。（ADR 0010 → 0011）
- 语义红 `#b84230` 只给失效 / 过期 / 危险确认。琥珀 `#f5a623` 只标“正在圈选”（hover ghost / target / lasso）；它不再当标注序号色，序号钉是 accent（ADR 0031）。
- 发丝线 / 浅面 / muted 由 accent color-mix 派生，不另立色相。
- 单 light 主题，不做 dark。chrome 暗色显式缓期：整套 `--wb-*` 要翻倍、玻璃材质要在暗底上重调，启动信号是 owner 在暗色环境里觉得刺眼（ADR 0031）。

## 材质

- 全场只有一种材质：F2 磨砂玻璃。配方 = `--wb-glass` 白 88%（`rgba(255,255,255,.88)`）+ `--wb-glass-blur`（`blur(20px) saturate(1.2)`）+ 0.5px 上缘内高光 + `--wb-sh-3` + 圆角 `--wb-r-glass` 14。CSS 类是 `.wb-glass`（`index.html`），token 在 `src/workbench/wb-tokens.css`。
- **常驻浮起的表面一律用 F2**：左栏面板、底部横条、右下按需卡、注入端的 `#ann-sidebar` 与工具条。注入端读不到 workbench 的 `--wb-*`，所以那份配方在 `src/client/annotate.js` 里是字面量；两端不许分家，对账靠 `e2e/dir-entry.spec.js` 的计算样式用例。
- 玻璃做的是材质感，不是真透视。更透的两档（白 62% / 白 38%）在评审时否掉：正文压在深色内容上读不清，一块常驻面板也不该有那种透视强度（ADR 0031）。要更透就是错的方向，不要试。
- ADR 0008 反模式清单里的“毛玻璃”一条已被 ADR 0031 取代，其余反模式（做旧质感、假材质、装饰性描边）不变。
- 瞬时浮层（菜单、对话框、评论卡）仍是白面 + 阴影阶梯 `--wb-sh-*`，不上玻璃：它们只掠过，不需要与画布共存。

## 字体与排印

- 系统字栈（Apple）。mono（ui-monospace / SF Mono）给机器精度信息：编号、日期、尺寸、id、引用号；读数 tabular-nums。
- **字阶四档**（ADR 0031），四档之外不另起字号：

  | token | 值 | 用在哪 |
  |---|---|---|
  | `--wb-t-title` | 600 15px/1.2 | 面板标题 |
  | `--wb-t-row` | 500 13px/1.2 | 列表行，正色 `--wb-fg`，不是 muted |
  | `--wb-t-body` | 400 12.5px/1.45 | 正文（标注正文、说明） |
  | `--wb-t-meta` | 500 11px/1.2 | 元数据，配 `--wb-font-mono` + `--wb-faint` |

- 两种消费方式。手写 CSS（`index.html` 的行与面板几何）写 `font:var(--wb-t-*) var(--wb-font)`，元数据档换 `var(--wb-font-mono)`。React 组件走 Tailwind：`wb-tw.css` 的 `@theme inline` 只把颜色、圆角、字体栈与字重接到 `--wb-*`，字号没有对应的 utility，所以组件里写的是与某一档相同的字面量（`text-[13px] font-medium`）——值必须落在四档上，不要在类名里发明新字号。
- 面板标题当前落在 13/600（左栏 wordmark、横条页名、弹出列表头），`--wb-t-title` 的 15/600 还没有消费点。这是 token 与实现的一处未对齐，改动标题字号时先决定往哪一边收。
- 区头 / eyebrow：11px semibold mono + 字距，英文大写（左栏段头）。
- 图标 = SVG 线性（lucide 族，约 1.7px 描边），emoji 不当图标。
- 文案不用“·”拼合信息：层级用版面表达（分行 / eyebrow / chip / 字重）。判据与案例归 workspace 的 topics/text-quality/ui-text.md 第 8 条。

## 外壳布局

画布铺满整个视口，chrome 全是压在它上面的浮层。`.wb` 只当定位容器，没有 flex 分栏。

- **左栏 = 浮动玻璃面板**（`#wbside`）。四缘距视口 `--wb-chrome-gap` 12px，下沿停在横条上方同一间距（`bottom = gap × 2 + --wb-strip-h`）。宽度 `--wb-side-w` 默认 252，拖拽范围 200–480，持久化（ADR 0016 的左栏那一半保留）。splitter 随面板浮起，常态不画线，hover 或拖拽时才现握把；折叠后贴左缘变成一条“点开”条。
- **底部横条**（`#wbstrip`）。居中的胶囊，高 `--wb-strip-h` 38，四段用 1px 结构缝隔开，从左到右一条读下来：在哪一页（Pages 开关 + 页名 + 类型标）→ 在哪一帧（‹ 1/6 › + map）→ 画布怎么看（缩放 · 回中 · 导出）→ 在干什么（交互｜标注 + 计数）。宽度由 `app/Strip.jsx` 量测后回写 `--wb-strip-w`，右下浮层靠它对齐横条右端。文档条目选中时中段前面多一个视口两段（窗口｜手机，`#wbviewport`，见下一条）；文档形态（两种视口都是）收起画布工具那一段，中段只剩它，横条本体留着。顶部不放任何东西。
- **模式 = 两段槽式控件**，取代 ADR 0011 的单钮：“交互”选中是白面（槽式分段的常规选中语言），“标注”选中是实心 accent。
- **视口 = 文档条目怎么被看**（2026-09-05，`lib/viewport.js`）。owner 的裁决是“doc 本身就是要展示的终态，而 prototype app 有多屏，所以 doc 可以只展示 html 本身，而 app 需要 section + frames”，要在手机上看的页面“应该给 html / url 加一个切换不同 viewport 的功能”；第一版把文档摆上画布，用过之后再裁：“html doc 的手机视图就不需要画布了，直接就是一个自适应大小（大约 viewport 高度 90%）的手机 screen，不需要状态栏和灵动岛；在画布上容易乱跑”。所以文档条目有两种看法，都是文档形态、都没有画布，横条中段的两段槽式控件切换，默认窗口：**窗口** = 文档 1:1 铺满整个视口（就是上面那条文档形态）；**手机** = 同一份文档装进一块手机屏，居中摆在舞台上——iframe 的 CSS 视口恒为 402 × 874（iPhone 17 Pro CSS px，与 iOS frame 同一个 preset），媒体查询与排版是真实手机布局；整块屏用 `transform: scale(k)` 缩到可用区（视口减掉底部横条那一带）高度的九成，横向在整个视口宽度里居中（左栏浮着，不让位，与窗口同一条规则），k 上限 1、窗口变了跟着重算（`phoneScaleFor`）；机壳跟设置里的“机壳 无 / 有”走——无 = 裸圆角屏（kit 的屏角）+ `--wb-sh-board` 板影，有 = kit 的钛框 + 黑边框——两种都不带状态栏 / 岛 / home 条，文档不是 app；网格、缩放、回中、图注、尺寸行、帧导航、导出都是画布工具，这里一样没有，中段只剩视口两段。url 条目照走同源代理。视口是页的偏好（`prefs.viewportByPage[pageId]`，只记手机、回窗口删 key），不进 registry、不进 URL；切换重装当前板，选中的条目跟着回来。标注锚点是元素选择器，两种视口共用同一本账本，钉子跟着元素走（在手机里跟着 k 一起缩）。手机视口不给画布条目：app 屏本来就在机壳里。
- **没有右栏**。它的两件事分别去了画布（钉子与评论卡）和右下的按需位置。画布两缘的展开胶囊、右下角单独的 HUD 一并删除，展开左栏的唯一入口是横条最左那颗钮。
- **右下按需槽**（`#wbdock`）。一块 280 宽的玻璃卡，两个住客永不同时出现：横条右端计数钮弹出的“这页的标注”列表，和选中 frame / section 时的 detail 面板（ADR 0026）。列表优先——点计数钮就是“我要浏览这页还剩什么”。Esc 只关最上面那层。
- **画布 dock**（section-nav + minimap）停在画布右下角、横条正上方。它不在横条正上方，因为那是底部 composer 的地盘。
- **浮起的 chrome 不许压住内容**。fit-to-view、回中、定位、首访聚焦都在“视口减掉 chrome 实际 bounding box”的可用区里算（`board-nav` 的 `chromeInsets`，量的是实际矩形而不是 token 常量，折叠与拖宽自动跟上）；composer 两侧按实际占位让开。这条只管画布：**文档形态不让位**——文档 1:1 铺满整个视口，面板与横条照样浮在文档上，文档底下不露画布（owner 2026-09-05：“html 不需要画布承载；我预期这个侧栏是 float 在画布上的，而不是挤压 html 的位置”；09-04 那版把 stage 收成让开左栏与横条的一栏，已撤）。被面板压住的正文靠收起面板来看。几何断言一律比 bounding box，不靠可见性断言（ADR 0023）。

## 左栏结构

从上到下：head → 搜索 → 段 → 行。设置视图在同一块面板里整屏替换（齿轮进，头部“‹ 预览”返回）。

- **head**：产品名 wordmark 13/600 + 一颗连接小点（绿通红断，整句话退进 title）+ 右端齿轮。第一眼必须是产品名与搜索，不是连接状态。
- **搜索**：整格 `--wb-fill` 药丸，⌘K / Ctrl+K 聚焦并全选，打字即筛，Esc 清空并交还焦点。focus 环画在整格上，不画在里面的 input 上（框中框）。
- **段**：最近（本地五条，行尾是**打开时刻**的相对时间，回答“我刚才在看什么”；空则整段不出）→ 页面（文件夹在前、散页在后，段尾一行“新建文件夹”）→ 内容（当前页的产物 / 草稿条目 + frame 树）。段头 11px semibold mono 淡色大写。
- **文件夹**（ADR 0032）：chevron + 夹图标的行，整行既是折叠钮也是入夹落点；右键 = 重命名 / 删除文件夹（删夹不删页）/ 新建文件夹。页行拖到夹行 = 入夹，拖回散页区 = 出夹，排序档是“默认”时夹内可拖重排；键盘路径在页行右键菜单里。折叠是本地先动、后台再写，其余动作写成功了才变，失败信息落在段尾一行红字上。
- **模板页**（Component Library / Example Library / Example HTML）默认不显示，开关在预览设置；当前页正好是模板页时它照旧显示，否则选中态没有落点。
- **frame 树**在“内容”区：延伸线结构（14px rail 槽位、字母与导线同轴、逐行拼接、末行收 └ 角，ADR 0014），点击定位 frame，与标注列表焦点双向同步，计数徽标红 = 含失效锚点。
- **行状态**：行高 27，`--wb-t-row` 13/500 正色；hover = `--wb-hover` 4%；选中 = `--wb-sel`（accent 10%）+ 600 字重，正色不退灰。选中与 hover 必须一眼分得开，这是这一档的全部目的。
- **行的构件**：页面行行首不放图标，标题从行的 8px 左内边距起——url / dir / 模板页一律如此，类型只在横条的类型标（画布 / 网页 / 文档）上出现（owner 2026-09-05：“有的 item 有 icon，有的没有，icon 是什么意思呢”；09-04 的 14px 类型槽已撤）。文件夹行的 chevron + 夹图标留着，那是结构不是类型。标题单行省略，行尾 11px mono tabular 淡色元数据、没有值就留空不许标题借位，夹内的页标题对到夹名那一列（padding-left 48）。拖放三态：入夹 = 整行一圈 accent 内描边，夹内重排 = 目标行上 / 下沿一条 accent 线，散页区 = 区块一圈淡 accent 描边。
- 行级动作（复制 locator、doc 导出、重命名）全在右键菜单，行尾不挂 hover 钮（ADR 0024）。

## 设置

齿轮进入，头部“‹ 预览”返回。行 = 56px 标签列 + 槽式分段。2026-09-05 精简成两段四行，按“这个设置作用在谁身上”分：

- **iOS 预览**：预览主题（Light / Dark，切被预览页面 `.ios-root` 的 `data-theme`）、机壳（无 / 有，值仍是 screen / bezel）、时间（系统 / 固定，固定时带时间输入）。三个只对 iOS kit 的内容有效，网页和文档页上没作用。
- **界面**：显示模板页（ADR 0032 的开关）。以后改 pinpoint 自己的设置都进这一段。

删掉的：缩放（横条已有 − / +）、画布纹理三态（固定网格）、Text 字号三档（固定标准）、字标字体六选一（只服务一个锁屏原型，默认 Helvetica 不再暴露）。它们的 prefs 键启动时一律回默认，`boot-prefs.js` 里有注释。“Frame”改叫“机壳”：词典里 frame 是帧。

## 画布（图纸人格）

- 双线网格 24 / 120px + sheet 外框。两档线色是 token：`--wb-grid-1` = accent 9%（120px 主线）、`--wb-grid-2` = accent 4%（24px 发丝线），`index.html` 不再写字面 color-mix。内图框与角部十字 2026-08-15 退役。
- **图注三档字**（ADR 0031）：区头 13/600 正色、屏名 12/500 淡、引用号 10.5 mono accent。引用号与屏名在同一行。画布基准是 scale 0.5，所以 `--wb-cap-*` 写的是观感值的两倍（26 / 24 / 21）。
- **尺寸行**在 frame 下方居中，mono 小字，只在这一帧 hover / 选中 / focus 时出（常驻太吵）。用 opacity 不用 display，行高留着、出没不推版面。导出快照与 `/api/frame` 没有 hover 语境，那两处照常显示。
- **“···”菜单钮**跟在屏名后面，是图注那条 flex 的末位；常态透明，这一帧 hover、焦点进图注、菜单开着时才现，按钮始终在 tab 序里。
- **frame 环两档**：hover = 2px accent 30%，选中 = 2px 实心 accent + 6px accent 14% 晕，选中压过 hover。hover 环用 outline 不用 box-shadow——doc 与组件机身自带 `--wb-sh-board`，box-shadow 会把板影顶掉。section 选中 = 大标题转 accent。这两档与标注的琥珀框天然分色：环是 accent、在机身外缘，标注框是琥珀、在元素上。
- 引用法：section 用字母，frame 用数字（A1 / A2 / B3）。人对 agent 说 A2；机器引用仍走 `@frame:id`。
- 比例读法：zoom 100% 视觉为原稿一半，写作 1:2（2026-08-17 基准重定标：视觉 = zoom × 0.5，0.5 烘在基准，ADR 0025）。

## 钉子与评论卡

画布上的钉子是标注的主体表达，不是列表的缩影（ADR 0031）。

- **钉子** `.ann-badge`：22px accent 实心圆 + 白字 mono + 2px 白描边 + 投影，常显、可点，两种模式下都在。白环让它在深色屏、彩色卡、白纸上都切得出来，所以常显不打折。聚焦或 hover 时补一圈 accent 32% 外晕。
- **评论卡** `.ann-bubble`：hover 钉子 120ms 才出（扫过不闪），离开给 90ms 宽限，指针可以移到卡上继续读；摆在钉子右边，右边放不下翻到左边。一次只出一张。
- 卡的形状：186 宽白面 + `--wb-sh-2` + 圆角 8，11px 正文，上面一条 11px mono 眉标 = 序号（accent）+ 这条指着什么（淡色）。作者标、灰底卡头、琥珀序号 chip 都已删除——一次只出一张卡，卡不必再自报是什么。
- **渲染开关**默认开，三态（隐藏批注 / 叠在页面 / 右侧通道）收在弹出列表头部的“···”里。右侧通道是文档形态用的：iframe 收窄，卡摊在父级 gutter 里，此时多张卡同时在，眉标里的序号是它们与钉子之间唯一的对应。
- **弹出列表**（“这页的标注”）：头 = 标题 + 总数 + “···”（三态与清空标注在里面，清空沿用 armed 红字 3s 两段确认）；行 = 序号钉 → 引用号 10.5 mono → 正文一行截断，hover 出“定位”。没有分组 eyebrow——引用号已经在每一行上。
- 列表不许盖住它自己定位到的那个气泡：被聚焦的钉子 / 卡 / flash 框会升到列表之上，“定位”之后画布再补一次横向让位把目标推出列表矩形。
- 锚点失效 = 整卡红描边 + 红浅面 + 文本退灰 + 序号钉转红，不用 tag。

## 选中模型与 note（2026-08-17）

- 画布点选：点 frame 图注（cap / dim 行）选 frame，点 section 大标题选 section，点板空白清选中；frame 内部点击永远留给原型交互，标注模式下选择让位给标注客户端（所以标注模式下选中的 frame 只可能是进模式之前选好的那一枚）。选中态 = 持久 accent 环 / 标题转 accent，与定位反馈的 flash 环分工。
- detail 面板显示选中对象的引用号 / 标题 / note，住在右下按需槽里（ADR 0026 的常驻容器随右栏一起退役）；note 编辑走 revision 链路（GET 拉 revision → PUT 带 baseRevision，409 保留草稿）。
- note 两级挂载：`sections[].note` 承载整组共用说明（图例 / 对比结论），`screens[].note` 承载单帧说明；都不渲染上画布。
- title 规矩：单行短名词短语；编号系统派生（A / B1）禁手写；禁“·”拼接；图例 / 意图 / 结论进 note。契约层硬拦换行，画布 caption 两行截断兜底。

## 组件惯用式

- 常驻浮起的外壳表面用 F2 玻璃（见“材质”）；瞬时浮层 = 白面 + 阴影阶梯 `--wb-sh-*`，无发丝描边（2026-08-11 扁平化；结构缝 08-13 回调）。
- 玻璃卡的 `backdrop-filter` 给 `position:fixed` 的后代造了包含块，卡自己又 `overflow:hidden`：卡里的菜单必须 Portal 出去，否则会被卡的下沿裁掉，DOM 断言全绿而人点不到。
- 分段 / 单选 = 槽式（灰槽 + 白面选中项）；瞬时动作组只借槽皮，不给单选态。
- ghost 优先，主行动才实心；hover / focus-visible / active / disabled 全态；过渡 ≤150ms，尊重 reduced-motion。
- 危险动作两段确认：armed 红字 3s。
- 圆角档位：控件 6 / 卡片 8 / 面板 12 / 模态 20；浮动玻璃族单独一档 `--wb-r-glass` 14（阶梯之外，只给这一族）；药丸只属于 badge / tag / 底部横条。
- 失败面板 = 实底 + `--wb-sh-3` + radius 14 + 标题 14/600，不用虚线框（虚线框读起来像拖放区）；它居中的是减掉 chrome 的可用区，不是整个视口。
