一、概况

Web 板吃 fragment，由 loader 包成画板；HTML 板吃完整文档，不做包装也不做 fragment 校验。 想在这里标注，页尾接一段 localhost 才拉的 annotate.js 即可——框架把整份文档当可标注区域，正文不必再打 surface 标记。
