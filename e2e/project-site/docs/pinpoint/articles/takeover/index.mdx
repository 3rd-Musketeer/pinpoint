# 用户接手

用户随时可以接手浏览器，顶部出现 [[takeover-banner]]。

接手前后对比如下。

| 维度 | 接手前 | 接手时 | 接手后 | 失败时 | 备注 |
|---|---|---|---|---|---|
| 顶栏 | agent 正在操作页面，用户只能看 | 横幅出现并说明谁在操作 | 用户直接点击和输入，agent 暂停 | 横幅提示接手没有成功并给出重试 | 横幅始终在页面最上方 |
| 输入 | agent 代填表单里的每一个字段 | 输入框解锁并保留已经填好的内容 | 用户改过的字段 agent 不再覆盖 | 保留用户输入不丢失 | 交回时逐项确认 |

| 状态 | 说明 |
|---|---|
| 接手 | 用户操作 |
| 交回 | agent 继续 |
